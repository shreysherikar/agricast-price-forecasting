# Security Policy

## Supported Versions

| Component | Supported |
|---|---|
| FastAPI Model Service (`src/`) | Yes |
| Django API Gateway (`django_gateway/`) | Yes |
| Next.js Frontend (`frontend_next/`) | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability or credential leak within this repository, please do not open a public issue. Instead, report it responsibly to:

- **Security Contact**: `shreyasherikar18@gmail.com`

Please provide:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept.
3. Potential impact.

Security patches will be reviewed and applied promptly.
